# Проверка на iPhone

Приложение: https://vadimbolshakov.github.io/word-cards/ — установлено на экран «Домой»
(Safari → «Поделиться» → «На экран „Домой“»). После публикации новой версии закройте приложение
в переключателе задач и откройте с иконки (иногда дважды), чтобы подтянулось обновление.

## Установка и обновление
- [ ] Иконка и название «Карточки» на экране «Домой»; открывается без адресной строки
- [ ] После деплоя новой версии и перезапуска приложения появляется новая тема

## Профили и настройки
- [ ] Первый запуск спрашивает имя; при одном профиле экран выбора пропускается
- [ ] Настройки (пауза, направление, порядок, повтор, скорость, «по кругу») сохраняются после перезапуска

## Ручной режим (🃏 Карточки)
- [ ] Звук лицевой стороны (или 🔊, если первый звук не сыграл), переворот тапом, звук перевода
- [ ] «Знаю» / «Повторить», свайп влево, «Пропустить», итог набора
- [ ] Двойной тап по «Знаю» засчитывается один раз
- [ ] Прогресс сохраняется после закрытия приложения из переключателя задач

## Автопоказ (▶)
- [ ] Цикл EN → пауза → RU → пауза; перевод появляется, когда звучит русская сторона
- [ ] Экран не гаснет минимум 2 минуты во время воспроизведения
- [ ] ⏸ / ▶, ⏮ / ⏭, «☆ Трудная»

## В кармане (🎧)
- [ ] Блокировка экрана в любой момент — воспроизведение продолжается 5+ минут
- [ ] Экран блокировки: текст карточки, «вперёд» / «назад»
- [ ] Пауза с экрана блокировки → play (известная проблема: может не продолжить до разблокировки)
- [ ] Пауза → разблокировать → заблокировать → play — продолжает с того же места
- [ ] Наушники выдернуты во время паузы — звук сам не включается
- [ ] Входящее уведомление/звонок не ломает воспроизведение после возврата (▶ продолжает)

## Навигация
- [ ] Свайп от левого края возвращает на предыдущий экран; уход с плеера останавливает звук

## Офлайн
- [ ] «Скачать для офлайна» → авиарежим → закрыть и открыть приложение → набор играет во всех режимах
- [ ] Нескачанный набор в авиарежиме → понятное сообщение «Нет звука…»

## Резервная копия
- [ ] «Сохранить прогресс в файл» открывает меню «Поделиться» → «Сохранить в Файлы»
- [ ] Удалить профиль → создать заново → «Восстановить из файла» → прогресс вернулся
